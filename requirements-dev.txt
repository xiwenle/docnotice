# - pytest-cov：CI 覆盖率报告插件（pytest --cov=app）
# - pip-audit：依赖漏洞审计（python -m pip_audit -r requirements.txt --no-deps；
#   2026-10-25 零通告基线，用法见 docs/TESTING.md §七）

#   进程 → 各自 import conftest → 各自 mkdtemp → 各自独立 app.db，不会互相 drop 表。
