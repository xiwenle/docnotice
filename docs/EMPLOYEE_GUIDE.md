# 员工使用指南（一页纸）

> 你只需要会两件事：**找资料、看通知。**

## 1. 登录

浏览器打开系统地址 → 输入管理员发给你的账号和初始密码 → **首次登录会要求改密码**，改成你自己的并牢记。

## 2. 找资料

- 左侧**分类目录**逐层展开，或顶部搜索框输入**资料标题 / 说明里的关键词**
- 列表里的状态标签含义：
  - **生效中**（绿）—— 当前有效，放心使用
  - **未生效** —— 还没到生效日期
  - **已过期** —— 请停止使用，等新版
- 点开资料可以**在线预览**（PDF 直接看；Word/Excel 显示文字内容；图片直接看图）；需要原件时点**下载**

## 3. 看通知

- 「通知」页列出所有和你相关的通知
- **打开**通知即记录"已查看"——不需要额外点任何按钮
- 工作台顶部会提醒你还有几条通知没看，点进去看完提醒就消失

## 4. 常见问题

| 问题 | 怎么办 |
|---|---|
| 忘记密码 | 联系管理员重置，重置后首登会再次要求改密 |
| 找不到想要的资料 | 换关键词试试；还没有就联系管理员（可能尚未上传） |
| 觉得资料内容有误 | 不要自行传播，联系管理员核实 |
| 改了自己密码 | 左侧栏用户菜单 →「修改密码」随时可改 |

---
*提示：资料是否有效由系统按生效日期自动计算，勿凭文件新旧判断。*
