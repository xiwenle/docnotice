# 项目全景图（drawio）

《作业资料系统》的架构、流程与接入点全景。**7 页，可编辑**。

## 文件

| 文件 | 说明 |
|---|---|
| `项目全景-流程与接入点.drawio` | **源文件**。用 draw.io 打开即可编辑 |
| `项目全景.svg` | 矢量图（选装；重跑生图脚本可再导出） |

重新生成：`python scripts/gen_project_diagram.py`（脚本是唯一真源，改图请改脚本）

## 7 页内容

| 页 | 主题 | 回答什么问题 |
|---|---|---|
| 01 | 系统总览 · 分层架构 | 系统由哪几层组成？每层有哪些模块？数据存在哪？ |
| 02 | 认证与权限 | 登录发生了什么？每个请求怎么鉴权？谁能做什么？ |
| 03 | 资料全生命周期 | 资料怎么建、怎么传文件、状态怎么算、怎么删和恢复？ |
| 04 | 通知生命周期与联动 | 通知怎么发？阅读状态怎么记？废止/替换如何改资料时效？ |
| 05 | 数据模型 · 17 张表 | 表之间怎么关联？哪些是实体、哪些是关联表？ |
| 06 | 备份与恢复 | 备份了什么？恢复的每一步是什么？互斥在哪？ |
| 07 | 接入点与部署运维 | 系统跟外界交互的所有边界在哪？怎么部署？ |

## 图例

| 颜色 | 含义 |
|---|---|
| 深蓝实心 | 主角色 / 关键实体 / 重要边界 |
| 浅蓝 | 正常业务模块 |
| 绿色 | 成功路径 / 数据写入 |
| 橙色 | 需要注意的约束、警告、待办 |
| 红色 | 危险操作、破坏性动作、已知缺陷 |
| 黄色 | **外部接入点**（①–⑥ / ①–⑩ 编号） |
| 灰色 | 基础设施、支撑组件 |

## 阅读建议

1. **新人上手**：01 → 03 → 04（先懂业务，再看实现）
2. **排查问题**：05（哪张表）→ 02（谁有权限）→ 06（能不能恢复）
3. **准备部署**：07 → 01（部署流程 → 分层理解）
4. **历史接入示意**：02 页底部 + 07 页底部
